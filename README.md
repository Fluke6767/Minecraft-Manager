# ⛏ Minecraft Manager (MG)

Minecraft Manager (MG) เป็นระบบจัดการเซิร์ฟเวอร์ Minecraft สำหรับ Linux/Ubuntu

## Features

- 🚀 Start / Stop / Restart Server
- 📊 Live Monitor
- 🟢 Server Status
- 🌐 Playit Status
- ☕ Java PID
- 👥 Online Players
- ⚡ TPS
- ⏱ MSPT
- 🧠 RAM Monitor
- 🔥 CPU Monitor
- 💾 Disk Monitor
- 📡 Network Monitor
- 📜 Console
- 🔄 Auto Restart
- 💾 Backup (Coming Soon)

Version : 2.0
